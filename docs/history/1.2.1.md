# OneBattery 1.2.1 (2026-10-30)

First released as **v1.0**; renumbered under Bradshaw Versioning on 2026-11-11.

## OneBattery by Flygon LC

First release: live battery stats, a health estimate and history, all stored on the phone.

- Live screen updating every 2 seconds: level, charging state, time to full or empty, watts, temperature, voltage and current.
- Battery health and wear compared with the S24 Ultra's 5,000 mAh design capacity.
- Battery level and temperature charts for 24h, 7d, 30d or all time, plus a capacity trend.
- Usage stats: average drain, how long a full charge lasts, charge count and temperatures.
- Logs a reading every 15 minutes, on plug and unplug, and after a reboot. Data stays on the phone.

The source for this release was not kept, so this commit holds only these notes.
The APK, where it still exists, is attached to the GitHub Release for this tag.
