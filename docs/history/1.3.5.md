# OneBattery 1.3.5 (2026-11-10)

First released as **v1.6**; renumbered under Bradshaw Versioning on 2026-11-11.

## The four Flygon LC house themes

The theme picker now offers the real Flygon LC house styles.

- Themes are now Flygon LC, Othello, System Boring and Night, using the house style catalog's colors, fonts and corner sizes.
- Bundled Press Start 2P, Source Sans 3, Instrument Serif and Instrument Sans so headings match the web.
- The app starts on Night in dark mode and on System Boring otherwise.

The source for this release was not kept, so this commit holds only these notes.
The APK, where it still exists, is attached to the GitHub Release for this tag.
