# OneBattery 1.3.3 (2026-11-10)

First released as **v1.4**; renumbered under Bradshaw Versioning on 2026-11-11.

## Theme picker

Settings gained a theme picker with a preview for each theme.

- Pick a theme at the top of Settings; the whole app switches at once and remembers the choice.
- Each theme sets its own colors, heading font and corner shape.
- Status bar icons turn dark on light themes so they stay readable.

The source for this release was not kept, so this commit holds only these notes.
The APK, where it still exists, is attached to the GitHub Release for this tag.
