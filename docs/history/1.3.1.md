# OneBattery 1.3.1 (2026-11-05)

First released as **v1.2**; renumbered under Bradshaw Versioning on 2026-11-11.

## What's draining your battery

A new card estimates which apps use the most battery over time.

- Apps ranked by estimated mAh over 24 hours, 7 days, 30 days or all time, with screen time and mAh per hour.
- Each app's change from the previous period, and its mAh per day when you tap it.
- A background activity list shows which apps keep services running or use the most background data.
- A Stop / restrict button opens that app's system page.

**Action required:** Grant Usage access from the new card so the tracker can tell which app is open.

The source for this release was not kept, so this commit holds only these notes.
The APK, where it still exists, is attached to the GitHub Release for this tag.
