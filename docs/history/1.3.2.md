# OneBattery 1.3.2 (2026-11-08)

First released as **v1.3**; renumbered under Bradshaw Versioning on 2026-11-11.

## Settings and a quieter notification

A settings screen to control how often the live notification updates.

- New Settings screen behind the gear icon.
- Choose how often the live notification updates, from every 10 seconds to every 15 minutes.
- Options to show live values or a static notification, and to update only while the screen is on.
- Sampling keeps running at full rate, so capacity measurements are unaffected.

The source for this release was not kept, so this commit holds only these notes.
The APK, where it still exists, is attached to the GitHub Release for this tag.
